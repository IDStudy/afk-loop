afk-loop  用法速查
============================================================

【第一次：装环境】
  Windows 10/11 64 位 + Python 3.10+
  pip install -r requirements.txt
  游戏画面：无边框窗口 / 全屏窗口化（独占全屏抓不到图）

【日常：挂机】
  双击 启动挂机.bat -> 选 2 -> 回车跳过警告 -> UAC 点"是"
  底部一行实时状态：界面 / 帧数 / 轮数 / 秒数

【流程】
  房间点开始 -> 匹配 -> 比赛 -> 排名结算点确认
  -> 奖励结算点屏幕 -> 加载 -> 回房间 -> 再开始
  认哪个界面、点哪里，全在 templates\ + afk_config.json，
  流程不一样就改状态表，不用动代码

【两种开局】只有第一步不同
  A 房间    大厅进玩法房间 -> 房间里点开始
            房间没有私密功能，路人进来又不准备会把你卡住
  B 大世界  大世界直接选玩法模式，不建房间就开始（长时间挂机推荐）
  走 B 只需把第 1 张模板换成大世界入口，第 2-5 张照旧

【怎么停】
  Ctrl+Alt+P           暂停 / 继续（暂停期间不动鼠标键盘）
  Ctrl+Alt+Q           终止（游戏里也有效）
  F9                   备用
  鼠标甩到屏幕左上角    急停
  黑窗口 Ctrl+C
  切到别的窗口 = 自动暂停，不抢焦点

【采模板】菜单选 1
  游戏切到对应界面 -> Ctrl+Alt+S 抓图 -> 拖框 -> 回车确认
  Ctrl+Alt+X 跳过    Ctrl+Alt+E 结束
    1_start.png         开局按钮：房间是【开始匹配】，大世界是【开始】
    2_matching.png      匹配中的固定元素
    3_racing.png        比赛中【晋级名额】四个字（别框 0/24 数字）
    4_rank_confirm.png  排名结算的【确认】（别框 (26秒) 倒计时）
    5_reward_click.png  奖励结算底部"点击任意位置返回"那行字
  采完选 3 看分数：每个界面 >= 0.90 才算稳

  ★ 只框永远不变的东西：数字 / 倒计时 / 进度 / 名额 / 光效都别框
  samples\ 里 5 张只是取景示例，分辨率绑定，不能直接用

【日志怎么读】
  一个界面一行，认不出界面（加载 / 过场）不写：
    房间里-开始 0.90  -> 点击(2258,117)
    匹配中 0.88
    比赛中 0.91
    排名结算-确认 0.94  -> 点击(2283,1452)
    奖励结算-任意点 0.88  -> 点屏幕[第1/3点](1280,1447)
       ✔ 第 1 轮  4.2 分钟
  ⚠没送进去            光标被锁 / 权限不够
  ⚠ 连点 3 次都没推进   那个位置点不动
  连续 120 秒认不出界面 -> 现场图存 out\fail\，日志给最高分前 3 名

【点了没反应】菜单选 5 点击测试
  鼠标停在按钮上按 Ctrl+Alt+T，三种投递方式一次测完
  结果同时写 out\clicktest.log
  B 有效 = 什么都不用改
  只有 C 有效 = afk_config.json 里 click_mode 改成 postmessage

【卡在奖励结算】
  这一步是"依次试点"：底部 -> 中间 -> 顶部，
  第一个点没推进就换下一个，成功就记住：
    "action": "click_anywhere",
    "points": [[0.5,0.94],[0.5,0.55],[0.5,0.06]]
  三个点都不行就自己改 points，或改成 "action": "click" 点模板中心

【注意】
  游戏必须无边框窗口 / 全屏窗口化
  换分辨率 / 换画质 / 游戏更新 UI -> 重采模板
  挂机时别碰鼠标，脚本点的是绝对坐标
  流程比别人多一步就在 states 里加一条，越靠前越先判

【比赛要按住油门】
  "3_racing.png" 那条："action": "none" -> "key_hold"，再加一行 "key": "w"

【文件】
  nfsm_afk.py              主程序，单文件
  afk_config.example.json  配置示例
  requirements.txt         依赖
  build.bat                打包 exe，产物 dist\afk-loop\
  启动挂机.bat              启动器：有 nfsm_afk.py 就跑源码，只有 exe 就跑 exe
  README.md                完整说明
  samples\                 取景示例（不能直接用）
  templates\               你的模板（首次运行是空的）
  afk_config.json          首次运行生成
  out\                     日志；fail\ 是没命中时的现场截图
