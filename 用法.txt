afk-loop —— 用法速查
========================================

【第一次：装环境】
  Windows 10/11 64 位 + Python 3.10 以上
  pip install -r requirements.txt
  游戏画面设置：改成【无边框窗口】/【全屏窗口化】
                独占全屏抓不到画面，脚本会一直显示"截图失败"

【流程】（本工具默认按这条链路走）
  房间点开始 -> 匹配 -> 比赛 -> 打完【排名结算】点确认
  -> 【奖励结算】点屏幕任意位置 -> 加载 -> 回房间 -> 再开始
  认哪个界面、点哪个按钮，全部由 templates\ 里的图 + afk_config.json 决定，
  流程不一样就改状态表，不用动代码。

【两种开局】这一步之后的流程完全一样
  A 房间：大厅进玩法房间 -> 房间里点开始
          这个模式的房间没有私密功能，路人中途进来又不准备，
          会把你卡在房间里，得手动踢人或重开
  B 大世界：在大世界里直接选玩法模式，不建房间直接开始
          不会被路人打断，长时间挂机推荐走这条
  程序认的是画面，不区分从哪进来。走 B 就把第 1 张模板换成
  大世界里的玩法入口 / 开始按钮，第 2-5 张照旧。
  samples\ 里的 5 张示例采的是 A（房间）这条线。

【怎么停】任意一条都行
  Ctrl+Alt+Q            主热键（游戏里也有效）
  F9                    备用
  鼠标甩到屏幕左上角     急停
  黑窗口里 Ctrl+C
  切到别的窗口 = 自动暂停（不抢焦点，随时切得出来）

【第一次：采模板】
双击 启动挂机.bat（或 python nfsm_afk.py）-> 选 1
  游戏切到对应界面 -> Ctrl+Alt+S 抓图 -> 拖框选中 -> 回车确认
  按顺序采这 5 张：
    1_start.png         开局那一步的按钮：从房间开始是【开始匹配】，
                        从大世界开始是【开始】按钮
    2_matching.png      匹配中的状态
    3_racing.png        比赛中【晋级名额】四个字（别框右边 0/24 那个数字）
    4_rank_confirm.png  排名结算界面的【确认】两个字（别框 (26秒) 倒计时）
    5_reward_click.png  奖励结算底部"点击屏幕任意位置返回房间"那行字
  某条不需要就 Ctrl+Alt+X 跳过，Ctrl+Alt+E 结束
采完选 3 看实时分数：每个界面都要 >= 0.90，低了重采

★ 一句话原则：只框【永远不变的东西】
  数字、倒计时、进度条、动画光效、会刷新的奖励物品 —— 框进去就永远匹配不上
  samples\ 里有 5 张取景示例，能看不能直接用（分辨率绑定，必须自己重采）

【日常：挂机】
双击 启动挂机.bat -> 选 2 -> 回车跳过警告
  UAC 弹窗点"是"。必须给管理员 —— 游戏是管理员启动的，普通权限下
  Windows 的 UIPI 会拦住所有点击注入（光标不动、点完没反应）。
  跑起来底部有一行实时状态：当前界面 / 帧数 / 轮数 / 跑了多少秒

【日志长什么样】
  一个界面一行，出错才多打一行：
    房间里-开始 0.90  -> 点击(2258,117)
    匹配中 0.88
    比赛中 0.91
    排名结算-确认 0.94  -> 点击(2283,1452)
    奖励结算-任意点 0.88  -> 点击(1180,1408)
       ✔ 第 1 轮  4.2 分钟
  加载 / 过场认不出界面属于正常，不写日志。
  点完界面没变会写 "⚠界面没变"，光标被锁会写 "⚠没送进去"，
  这一轮也不会计入轮数。

【点了没反应怎么查】
菜单选 5「点击测试」，鼠标停在按钮上按 Ctrl+Alt+T，
三种投递方式一次测完，结果同时写进 out\clicktest.log
  B 有效 = 什么都不用改
  只有 C 有效 = afk_config.json 里 "click_mode" 改成 "postmessage"

【没命中怎么办】
  连续 45 秒认不出界面，脚本会自动把当时的画面存到 out\fail\，
  并把分数最高的 3 个模板写进日志。拿那张图跟模板比一下就知道差在哪

【卡在奖励结算 / 点完界面不动】
  日志写 "⚠界面没变" 就是点到了不能点的地方（奖励卡片、图片、空白）。
  老配置最后一步点的是客户区中央 50%,55%，那个位置正好压在奖励卡上，
  所以框的是底部提示也没用 —— 模板只管认界面，不管点哪。
  现在默认 "action": "click"（点模板中心，框哪点哪），老配置第一次启动会
  自动升级，原文件备份成 afk_config.json.bak。
  想点别处就改用 "click_anywhere" 并自己配 "point"（0~1 的比例），
  比如面板四周的空白："action": "click_anywhere", "point": [0.02, 0.5]

【注意】
  游戏必须是无边框窗口 / 全屏窗口化，独占全屏抓不到图
  改了分辨率、换了画质、游戏更新改了 UI -> 重新采模板
  挂机时别碰鼠标，脚本点的是绝对坐标
  流程比别人多一步（大世界要先开菜单找入口）就在 afk_config.json 的
  states 里加一条，顺序就是优先级，越靠前越先判

【比赛要按住油门】
afk_config.json 里 "3_racing.png" 那条：
  "action": "none"  ->  "action": "key_hold"
  再加一行：          "key": "w"

【文件】
  nfsm_afk.py              主程序，单文件
  afk_config.example.json  配置示例（窗口、阈值、状态表）
  requirements.txt         依赖
  build.bat                一键打包成 exe，产物 dist\afk-loop\
  启动挂机.bat              源码版启动器，自动申请管理员
  README.md                完整说明：原理 / 采模板原则 / 故障排查
  samples\                 取景示例图，不能直接当模板用
  templates\               你自己的模板放这（首次运行时是空的）
  afk_config.json          首次运行自动生成，你自己的配置
  out\                     运行日志，fail\ 是没命中时的现场截图
