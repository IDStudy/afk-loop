NFSM 热湾淘汰赛挂机 —— 用法
========================================

【流程】
  房间点开始 -> 匹配 -> 比赛 -> 打完【排名结算】点确认
  -> 【奖励结算】点屏幕任意位置 -> 加载 -> 回房间 -> 再开始

【怎么停】任意一条都行
  Ctrl+Alt+Q            主热键（游戏里也有效）
  F9                    备用
  鼠标甩到屏幕左上角     急停
  黑窗口里 Ctrl+C
  切到别的窗口 = 自动暂停（不抢焦点，随时切得出来）

【第一次：采模板】
双击 启动挂机.bat -> 选 1
  游戏切到对应界面 -> Ctrl+Alt+S 抓图 -> 拖框选中 -> 回车确认
  按顺序采这 5 张：
    1_start.png         房间里的【开始匹配】按钮
    2_matching.png      匹配中的【结束匹配】按钮
    3_racing.png        比赛中【晋级名额】四个字（别框右边 0/24 那个数字）
    4_rank_confirm.png  排名结算界面的【确认】两个字（别框 (26秒) 倒计时）
    5_reward_click.png  奖励结算底部"点击屏幕任意位置返回房间"那行字
  某条不需要就 Ctrl+Alt+X 跳过，Ctrl+Alt+E 结束
采完选 3 看实时分数：每个界面都要 >= 0.90，低了重采

★ 一句话原则：只框【永远不变的东西】
  数字、倒计时、进度条、动画光效、会刷新的奖励物品 —— 框进去就永远匹配不上

【日常：挂机】
双击 启动挂机.bat -> 选 2 -> 回车跳过警告
  UAC 弹窗点"是"。必须给管理员 —— 游戏是管理员启动的，普通权限下
  Windows 的 UIPI 会拦住所有点击注入（光标不动、点完没反应）。
  跑起来底部有一行实时状态：当前界面 / 帧数 / 轮数 / 跑了多少秒

【日志长什么样】
  一个界面一行，出错才多打一行：
    房间里-开始 0.90  -> 点击(2258,117)
    匹配中 0.88
    比赛中 0.91
    排名结算-确认 0.94  -> 点击(2283,1452)
    奖励结算-任意点 0.88  -> 点屏幕(1280,847)
       ✔ 第 1 轮  4.2 分钟
  加载 / 过场认不出界面属于正常，不写日志。
  点击后画面没动会写 "⚠没反应"，这时脚本会自动补一次窗口消息。

【点了没反应怎么查】
菜单选 5「点击测试」，鼠标停在按钮上按 Ctrl+Alt+T，
三种投递方式一次测完，结果同时写进 out\clicktest.log
  B 有效 = 什么都不用改
  只有 C 有效 = afk_config.json 里 "click_mode" 改成 "postmessage"

【没命中怎么办】
  连续 45 秒认不出界面，脚本会自动把当时的画面存到 out\fail\，
  并把分数最高的 3 个模板写进日志。拿那张图跟模板比一下就知道差在哪

【注意】
  游戏必须是无边框窗口 / 全屏窗口化，独占全屏抓不到图
  改了分辨率或游戏换了 UI 版本 -> 重新采模板
  挂机时别碰鼠标，脚本点的是绝对坐标
  第 5 步点的是客户区 50%,55%（屏幕中央偏下），
  要换位置改 afk_config.json 里 "5_reward_click.png" 那条的 "point"

【比赛要按住油门】
afk_config.json 里 "3_racing.png" 那条：
  "action": "none"  ->  "action": "key_hold"
  再加一行：          "key": "w"

【文件】
  nfsm_afk.py       主程序
  afk_config.json   窗口、阈值、界面状态表
  templates\        模板图（一个界面一张 png + meta.json 记录取景位置）
  out\              运行日志，fail\ 是没命中时的现场截图
  _selftest.py      离线自测（改完状态机跑一下，不碰游戏）
