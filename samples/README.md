样例图 —— 只能看，不能直接用
================================================

这 5 张是我在自己机器上采的模板（2560×1600，DPI 125%，DSR 全屏）。

它们的作用只有一个：**告诉你该框哪一块**。

为什么不能直接用：

  模板 = 一块像素。像素直接绑死三件事 —— 分辨率、UI 缩放、画质设置。
  你把我的 1920 下的界面拿去比 2560 下采的图，分数永远在 0.4 左右，
  脚本会一直显示"认不出界面"，然后你会觉得是脚本坏了。

  实际上它没坏，是你的图跟别人的图对不上。


每条该怎么框
------------------------------------------------

  1_start.png         房间里的【开始匹配】按钮
                      框按钮本体，别带背景（背景会随车辆/场景变）

  2_matching.png      匹配中的【结束匹配】按钮
                      只框按钮文字，别框转圈动画

  3_racing.png        比赛中【晋级名额】四个字
                      ★ 别框右边的 0/24 —— 名额数字会变
                      ★ 别框计时器和速度表 —— 一直在跳

  4_rank_confirm.png  排名结算的【确认】两个字
                      ★ 别框后面的 (26秒) —— 倒计时每秒都在变
                      这是最容易踩的坑，框整块按钮就废了

  5_reward_click.png  奖励结算底部"点击屏幕任意位置返回房间"那行字
                      ★ 别框任务卡片 —— 进度 4/6、91/200 每局都不同
                      这行字只是用来"认出在这个界面"，点哪由配置里的 point 决定


采完怎么自查
------------------------------------------------

  菜单选 3，停在每个界面看分数：
    你的机器上，5 个界面都要 >= 0.90

  低于 0.82 就重采那一张。
