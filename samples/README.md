# 样例图 —— 只能看，不能直接用

这 5 张是模板采集的示例，采自：

- 系统分辨率 **2560×1600**，Windows 缩放 **125%**
- 游戏客户区 **2560×1540**（无边框全屏）
- 取景位置记录在 `templates\meta.json`（采集后自动生成，仓库里没有这个文件）

它们的作用只有一个：**告诉你该框哪一块**。

> **这 5 张采自「创建房间 → 房间内点开始」这条线。**
> 如果你是从大世界直接选玩法模式开局（不需要房间，见 README「两种开局方式」），
> 第 1 张 `1_start.png` 要换成大世界里那个入口 / 开始按钮，后面 2–5 完全一样。

## 为什么不能直接用

模板 = 一块像素。像素直接绑死三件事 —— 分辨率、UI 缩放、画质设置。

别人在 1920×1080 下截的界面，拿来比 2560×1540 下采的图，分数永远在 0.4 左右，
脚本会一直显示「认不出界面」，然后你会以为脚本坏了。

实际上它没坏，是两块图对不上。**换分辨率就必须重采。**

## 每条该怎么框

| 文件 | 框什么 | 别框什么 |
|---|---|---|
| `1_start.png` | 房间里的【开始匹配】按钮本体 | 别带背景，背景会随车辆/场景变 |
| `2_matching.png` | 匹配中的【结束匹配】按钮文字 | 别框转圈动画 |
| `3_racing.png` | 比赛中【晋级名额】四个字 | 别框右边的 `0/24`，名额数字会变；也别框计时器和速度表 |
| `4_rank_confirm.png` | 排名结算的【确认】两个字 | ★ 别框后面的 `(26秒)`，倒计时每秒都在变 —— 这是最容易踩的坑，框整块按钮就废了 |
| `5_reward_click.png` | 奖励结算底部「点击屏幕任意位置返回房间」那行字 | ★ 别框任务卡片，进度 `4/6`、`91/200` 每局都不同 |

第 5 张特别注意：**框哪就点哪**（`action: click` = 点模板中心）。
所以要框底部那行「点击屏幕任意位置返回」的固定提示，不要框中间那块奖励卡片 ——
卡片点上去只是被选中，界面不会推进。老版本用固定比例点（客户区 50%,55%），
那个位置正好压在奖励卡上，换分辨率后必卡，已经改掉了。

## 采完怎么自查

菜单选 3，停在每个界面看分数：

- 你的机器上，5 个界面都要 **≥ 0.90**
- 低于 **0.82** 就重采那一张
